# note-new

한 과목·한 주제를 처음 배우는 사람이 **끝까지 읽고 문제까지 풀 수 있게** 만드는 장문 한국어
HTML 강의노트 제작 스킬입니다. [Claude Code](https://claude.com/claude-code)의 스킬로 쓰거나,
사람이 읽는 제작 지침서로 써도 됩니다.

산출물은 **단일 HTML 파일 하나**입니다. 외부 연결이 없어 인터넷 없이 다른 컴퓨터에서도 열립니다.

- **읽힌다** — 정의·수식·단서를 줄이지 않고, 그 둘레에 사전지식·직관·현실 예시·말풀이를 덧댑니다.
- **만져진다** — 그림은 삽화가 아니라 실험입니다. 모든 값이 데이터에서 그 자리에서 계산되고,
  슬라이더·버튼·카드를 움직이면 정직하게 반응합니다.
- **참조된다** — 우측 패널이 스크롤을 따라와 "지금 절의 식과 용어"만 보여 줍니다.
- **풀린다** — 문제 유형 지도, 유형별 풀이 틀, 해설이 접힌 연습문제, 시험장 요약 카드까지.

## 이 스킬의 중심 생각

**게이트를 본문보다 먼저 짭니다.** 글을 쓴 뒤 검사하면 "나중에 발견해 고치고 그것을 성과로
보고하는" 패턴이 반복되고, 이미 그 숫자를 전제로 쓴 문장들까지 함께 틀어집니다. 그래서
데이터 → 수치 게이트 → 본문 순으로 갑니다.

**집필이 끝나면 문장만 보는 별도 패스를 돌립니다.** 방금 쓴 쪽은 자기 습관을 좋은 글로 여기기
때문에, 같은 패스에서는 어색한 한국어가 잡히지 않습니다. 이 저장소의
[`references/hunt-pass.md`](references/hunt-pass.md)가 그 절차이고, 실제 노트에서 측정한
열한 가지 유형이 예문과 함께 정리돼 있습니다 — 극적 제시, 지워도 되는 문장, 글쓴이만 아는 은어,
쓸데없이 쪼갠 문장, 영어 관사를 옮긴 '하나/한', 다의어를 첫 뜻으로 고정(line→'줄', place→'자리'),
유정물 전용 말을 무정물에(bring in→'데려오다'), 영어 주어를 그대로('우리', "6장이 증명했다"),
명사로 한 번 더 싸기(the fact that→'…라는 사실입니다'), 번역투와 피동, 감정 강요와 의인화.

## 설치

```bash
git clone https://github.com/T19340/note-new.git ~/.claude/skills/note-new
```

Windows PowerShell:

```powershell
git clone https://github.com/T19340/note-new.git "$env:USERPROFILE\.claude\skills\note-new"
```

Claude Code를 다시 시작하면 스킬 목록에 나타납니다. 갱신은 `git pull`.

### 설치 확인

딸려 있는 최소 예제를 조립해 봅니다(경로가 상대경로라 그대로 돌아갑니다).

```bash
cd ~/.claude/skills/note-new/assets/example
python ../assemble.py note.json
python ../gates/gate_struct.py out.html terms.txt   # FAILS: 0
python ../gates/korean_scan.py out.html             # HARD 0건
rm out.html
```

### 필요한 것

- **Python 3** — 게이트 스크립트 전부. Windows에서는 한글 파일 때문에 `PYTHONUTF8=1`이
  필요합니다(`setx PYTHONUTF8 1`로 한 번 설정해 두면 됩니다).
- **Chrome**(선택) — `render_check.py`의 헤드리스 렌더·스크린샷에만. 없으면 그 게이트만 건너뜁니다.
- **Pillow**(선택) — 긴 문서를 조각으로 자를 때만.

## 무엇이 들어 있나

```
SKILL.md                     작업 순서 7단계
SOURCES.md                   이 방법론의 각 조각이 어디서 왔는지
references/
  content.md                 절 구조와 설명 방식 — 진화의 사슬, 하나의 데이터 관통, 시험 대비 층
  figures.md                 그림 설계 — 검증된 인터랙션 아홉 가지, 데이터 계약
  gates.md                   게이트 여섯 종과 각각이 잡는 결함
  hunt-pass.md               어색한 한국어를 잡는 별도 패스, 열한 유형
  build.md                   조립과 납품 — 매니페스트, 함정, 체크리스트
assets/
  shell/                     blueprint 시각 셸(CSS, 인라인 MathJax 2.1MB, 수식 클릭-복사)
  js/                        의존성 0 캔버스 라이브러리 + 퀴즈·폭포·축 엔진
  gates/                     검사 스크립트 8종
  example/                   위 자산만으로 조립되는 최소 노트 한 벌 (여기서 시작하면 빠릅니다)
  assemble.py                매니페스트 기반 조립기
evals/                       발동 조건·제작 품질 평가 세트
```

### 게이트

| 스크립트 | 무엇을 잡나 |
|---|---|
| `gate_numbers_template.py` | 원자료의 항등식, 본문이 인용한 계산값, 연습문제 답 |
| `gate_struct.py` | 절 id와 목차·패널·scroll-spy 불일치, 그림 번호 구멍, 외부 의존, 수식 클릭-복사 적용률 |
| `korean_scan.py` | 문체 — HARD(차단) / 판정(전량 읽기) / 통계(문장 연타·낱말 편중) |
| `check_content_style.py` | 번역체·AI 결함을 하드/소프트로 구분 |
| `texscan.py` | 백슬래시 소실 등 조용한 수식 파손 |
| `render_check.py` | JS 오류, 빈 캔버스, MathJax 오류, readout NaN, 레이아웃, 패널 카드 넘침 |
| `audit_prep.py` · `itest-template.js` | 런타임 감사 훅, 클릭 시나리오 |

`korean_scan.py`의 **낱말 편중표**가 이 도구들 중 유일하게 *아직 모르는 결함*을 잡습니다.
본문 빈출 낱말을 세어, 주제어가 아닌 말이 상위에 있으면 그 말이 여러 영어 낱말을 혼자 떠맡고
있다는 신호로 봅니다. 실측 사례: 확산모형을 다루는 장에서 '자리'가 48회로 1위였고(평균·잡음·
분산보다 위) place·point·spot·juncture와 "글의 대목"까지 감당하고 있었습니다.

## 발동 조건

스킬 이름을 직접 말하거나("note-new로 …"), 이 방법론으로 만든 기존 노트를 가리켜 "같은
양식으로", "이 노트 이어서 다음 강의"라고 할 때만 발동합니다. 형식을 지정하지 않은 일반
요청("강의노트 만들어줘")에는 어떤 형식을 원하는지 먼저 묻습니다. 발동 시험 12개 중 11개
통과(지목 시 3/3, 일반 요청 0/3).

## 쓰지 않는 곳

한 화면짜리 메모, 슬라이드, 짧은 요약에는 과합니다. 원본 자료를 형식만 바꿔 옮기는 변환
작업이라면 본문을 다시 쓰지 말아야 하고, 실행 가능한 코드가 주인공인 주제라면 동반 노트북이
따로 필요합니다.
