# 조립과 납품

## 1. 폴더 구성

노트 하나가 소스 폴더 하나를 쓴다.

```
<노트 소스>/
├── note.json          # 조립 매니페스트 (assets/note.example.json 복사)
├── data.json          # 숫자의 유일한 출처
├── head_extra.html    # 노트별 CSS + </style></head><body> + 마스트헤드
├── p0.html … p5.html  # 본문 조각(요지·목차, 파트별)
├── panel.html         # </div> + 우측 패널(목차·참조 카드) + 참고문헌 + 고지 + 푸터
├── spy.js             # scroll-spy + </body></html>
├── figs.js            # 그림 코드(여러 개로 나눠도 된다)
├── gate_numbers.py    # 주제별 수치 게이트
└── terms.txt          # (선택) 본문에 반드시 나와야 할 용어
```

조립: `python <skill>/assets/assemble.py note.json` → `out.html`.

이 구성을 처음부터 손으로 만들 필요는 없다. `<skill>/assets/example/`이 위 파일을 모두 갖춘
최소 노트(절 2·그림 2)이고 게이트를 통과한 상태다. 복사해 와서 `note.json`의 `skill_assets`를
스킬 경로로 고치고 내용을 갈아끼운다. `terms.txt`를 쓸 때는 `assets/terms.example.txt`에
무엇을 넣어야 게이트가 쓸모 있는지 적어 두었다.

조각으로 나누는 이유는 한 응답에 큰 파일을 통째로 쓰면 출력 상한에 걸려 그 작업이 통째로
날아가기 때문이다. 수정할 때도 조각을 고쳐 다시 조립한다. 완성본 HTML을 직접 편집하지 않는다.

## 2. 셸이 기대하는 뼈대

`head_extra.html`은 `</style>`로 시작해서 마스트헤드까지 쓴다. 조립기가 그 앞에 셸 CSS와
컴포넌트 CSS를 붙인다. 본문 조각은 `.content` 안에 들어가고, `panel.html`이 `.content`를 닫고
패널 레일을 연다.

절 헤딩은 `<h3 class="sec" id="s11"><span class="sn">1.1</span> 제목</h3>` 꼴이어야 한다.
패널의 참조 카드는 `<div class="fcard" data-sec="s11">`로 절 id와 묶이고, `spy.js`의
`targets` 배열과 `secName` 맵도 같은 id를 쓴다. 이 네 곳(섹션·목차·카드·spy)이 어긋나면
구조 게이트가 잡는다.

## 3. 수식은 전부 클릭하면 복사되게 쓴다

독자가 노트의 수식을 자기 과제나 메모로 옮길 때 쓰는 기능이다. 셸이 이미 갖추고 있으므로
**쓰는 쪽이 문법만 지키면 된다.**

```html
<div class="eq" data-tex="\text{FV} = \text{PV}(1+r)^n"></div>        <!-- 블록 -->
이자율이 <span class="eqi" data-tex="r = 0.07"></span>이면 …            <!-- 인라인 -->
```

태그는 비워 둔다. 조립기가 붙이는 스크립트가 `data-tex`를 읽어 `\[…\]`·`\(…\)`로 채우고,
클릭 핸들러와 "⊕ CLICK TO COPY LATEX" 라벨을 단다. `head_extra.html`에 `<div id="toast">`가
있어야 복사 알림이 뜬다(예제에 들어 있다).

**본문에 `\[ … \]`나 `\( … \)`를 직접 쓰지 않는다.** 이렇게 써도 MathJax가 렌더하므로 화면상
멀쩡해 보이고 렌더 게이트도 통과한다. 그래서 조용히 기능만 빠진다 — 실제로 이 규칙이 문서에
없던 동안 만든 노트들의 적용률이 7~47%까지 떨어졌다. 구조 게이트가 적용률 90% 미만을 잡는다.

예외는 패널의 참조 카드(`.fb-eq`)다. 읽기용이라 클릭 대상이 아니고, 게이트도 세지 않는다.

## 4. 오프라인 요건

다른 컴퓨터에서 인터넷 없이 열려야 한다. 그래서 외부 `<script src>`와 `<link>`를 두지 않고
MathJax를 인라인으로 넣는다(약 2.1MB). 폰트는 시스템 폰트로 폴백된다. 그림은 캔버스로 그리므로
이미지 파일이 없다. 구조 게이트가 외부 의존 0을 확인한다.

여러 노트를 같은 폴더에 두면 서로 링크할 수 있다(`<a href="다른노트.html#s23">`). 링크를 걸면
납품할 때 두 파일을 같은 폴더에 두라고 알려 준다.

## 5. 자주 밟는 지뢰

- **컨트롤 id와 섹션 id 충돌** → 컨트롤에 `f7-` 같은 접두어.
- **대문자 변환** — 셸의 `.figtag`·표 머리글·`summary`가 `uppercase`라서 `f(x)`가 `F(X)`가
  된다. 수식 기호가 든 라벨은 `text-transform:none`으로 덮는다.
- **전역 `svg{}` 규칙** — MathJax 수식 SVG까지 늘어난다. `.fig > svg`로 한정한다.
- **`.content{min-width:0}`** — 없으면 넓은 표가 그리드를 밀어 레이아웃이 무너진다(셸에 이미 있다).
- **패널 수식 넘침** — 264px 폭이다. 긴 식은 `\begin{aligned}`로 연산자 앞에서 줄을 바꾸고,
  분수는 `\tfrac`. `render_check.py`의 카드 펼침 렌더로 확인한다.
- **fcard의 부등호** — `<`, `>`는 `&lt;`, `&gt;`로. 그대로 두면 DOM이 깨진다.
- **heredoc으로 HTML 쓰기 금지** — bash heredoc에서 `\\`가 `\`로 뭉개져 수식이 조용히 깨진다.
  파일은 Write 도구로 쓴다.

## 6. 납품

0. **`python gate_deliver.py <조립본.html>`이 통과해야 납품한다.** 이 하나가 구조·문체·
   사냥 패스를 묶어서 본다. 특히 사냥 패스 기록(`hunt.md`)이 **지금 빌드의 해시와 맞는지**
   확인하므로, 본문을 고치면 기록이 낡아 다시 통독해야 한다. 아래는 그 게이트가 보는 것들이다.

   **납품 전 두 가지를 반드시 통과한다.** `python gate_struct.py out.html`이 FAILS 0이고,
   `python korean_scan.py out.html --triage triage.txt`가
   통과해야 한다(HARD 0 + 판정 항목 전량 기록). `triage.txt`도 소스와 함께 저장한다 —
   그 파일이 판정 목록을 읽었다는 유일한 증거다. 그리고 사냥 패스(`hunt-pass.md`)를 실제로 돌렸는지 확인한다 — 린터는 알려진 패턴만 잡으므로 통과가
   자연스러운 한국어의 증거가 아니다. 이 둘을 건너뛰면 다른 게이트를 다 통과하고도 한국어가
   엉망인 노트가 나간다(실제로 그렇게 나간 적이 있다).
1. 완성 HTML을 사용자가 쓰는 폴더에 복사한다(파일명은 과목·주제가 드러나게).
2. **소스 폴더도 함께 저장한다.** 조각·매니페스트·데이터·게이트·그림 코드. 임시 폴더에만 두면
   세션이 끝났을 때 다음 강의를 이어 만들 수 없다.
3. 저장한 소스로 다시 조립해 납품본과 같은지 확인한다(`python assemble.py && cmp out.html ../노트.html`).
   경로가 바뀌므로 매니페스트의 `skill_assets`와 게이트의 데이터 경로를 함께 손본다.
4. 보고에는 무엇을 확인했고 무엇이 빠졌는지 적는다. 자료가 없어 추정으로 채운 부분, 사용자가
   확인해 주어야 할 부분(수업에서 쓰는 표기법 등)을 분명히 남긴다.
5. 다음 강의를 이어 만들 수 있도록 기록(메모리·README)에 소스 경로와 데이터 구조를 남긴다.
